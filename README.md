# monopoly
monopoly


## Текущая версия

- Поддерживается до 8 игроков в одной комнате.
- Для каждого игрока предусмотрены отдельные цвет и фишка.
- При попытке войти в заполненную комнату клиент получает уведомление.

## Локальный запуск автотестов

Требуется Node.js 20 или новее.

```bash
npm install
npx playwright install chromium
npm test
```

Отдельные наборы:

```bash
npm run test:mechanics
npm run test:building
```


## Исправления интерфейса

- Перестроена компоновка на планшетной ширине: игровое поле показывается отдельно, панели управления и чата переходят ниже него.
- Исправлено обрезание длинных названий клеток и переполнение текста.
- Уменьшены колоды и элементы управления на небольших экранах.
- Кнопка ипотеки убрана из центральной зоны: управление ипотекой остаётся в панели имущества.


## Новый интерфейс: классика + минимализм

Игровое поле сохраняет классическую палитру настольной «Монополии»: тёплый кремовый фон, зелёная рамка и цветные группы улиц. Справа размещена отдельная панель управления имуществом, строительством, ипотекой, игроками и хроникой. Визуальные элементы упрощены: меньше теней, спокойные поверхности, компактные кнопки и карточки. На узких экранах панели переходят под игровое поле.


## Визуальная система Classic Minimal

- Единая палитра: тёплый кремовый фон, глубокий настольный зелёный, бумажные поверхности и приглушённые золотистые акценты.
- Игровое поле расположено слева, отдельная панель состояния партии и управления — справа.
- В панели собраны капитал, список собственности, действия с недвижимостью, игроки и игровая хроника.
- Лобби, модальные окна торговли/аукциона, карты событий и игровые контролы приведены к одной визуальной системе.
- На узких экранах поле и панель управления располагаются вертикально.


## Игровые анимации и интерактивные карточки

- Фишка получает короткую анимацию прибытия, когда её позиция меняется после хода.
- Кубики получают отдельную анимацию приземления после броска.
- Клетки игрового поля реагируют на наведение и выделяют позицию активного игрока.
- Нажатие на клетку открывает карточку объекта: стоимость, владелец, тарифы аренды, строительство и примечания.
- Системные игровые события показываются в компактных уведомлениях и остаются в хронике партии.
- Для системных сообщений используется безопасное создание DOM-узлов через `textContent`.
- Анимации отключаются или сокращаются при включённом `prefers-reduced-motion`.

## Исправление анимации кубиков

- Убрано быстрое вращение кубиков и мигание граней.
- Частота смены случайных значений во время броска снижена до более спокойной.
- Вместо вращения используется короткий подъём и мягкое возвращение на место.
- После броска остаётся небольшая анимация приземления без вспышки и резкого масштабирования.
- Добавлена поддержка `prefers-reduced-motion`.


## Анимация перемещения фишек по клеткам

- При обычном перемещении фишка визуально проходит каждую промежуточную клетку по часовой стрелке.
- Используется временная копия фишки поверх поля; итоговая игровая позиция и расчёты остаются прежними.
- Перемещение выполняется короткими равномерными шагами с мягким масштабированием.
- Телепортация в тюрьму и другие нестандартные перемещения не проигрываются как обычный маршрут.
- Проверка встроенного JavaScript через `node --check` пройдена; браузерный прогон не выполнялся.


## Анимация покупки и строительства

- При покупке недвижимости клетка получает мягкую золотистую подсветку.
- При строительстве подсвечивается соответствующая клетка, а дом или отель появляется с короткой анимацией.
- После действия выводится компактное уведомление с названием объекта и результатом.
- Эффекты запускаются после изменения состояния игры и не влияют на расчёты денег, аренды, собственности или запаса зданий.
- Встроенный JavaScript проверен через `node --check`; дубликатов HTML ID нет. Браузерный визуальный тест не выполнялся.


## Экран банкротства и финансовые события

- Добавлено отдельное модальное окно с итогом банкротства.
- Окно открывается при системном событии «Банкротство» и закрывается кнопкой продолжения партии.
- Существующая обработка долгов, передачи собственности кредитору, возврата зданий банку и аукциона оставлена без изменений.
- История денежных операций и событий остаётся в существующей игровой хронике; новые расчёты финансов не добавлялись.
- Встроенный JavaScript прошёл `node --check`; дубликатов HTML ID нет. Браузерные сценарии этой версии проверены в Chromium.


## Финансовая статистика и итоги партии

- Добавлена финансовая сводка: наличные учитываются в балансе, активы включают стоимость недвижимости и зданий, ипотека учитывается как обязательство в размере 55% цены объекта: 50% сумма залога и 10% годовых от суммы залога при выкупе.
- Для каждого участника рассчитывается ориентировочная чистая стоимость капитала: наличные + стоимость недвижимости + стоимость построек − ипотечное обязательство.
- Добавлен рейтинг игроков по чистому капиталу.
- Добавлена лента последних финансовых операций, формируемая из игровых системных сообщений.
- Финансовая лента включается в сетевой снимок состояния и передаётся участникам комнаты.
- После окончания партии показывается итоговый экран с победителем и рейтингом оставшихся игроков.
- Оценка капитала является справочной игровой метрикой, а не официальным правилом определения победителя в классической настольной версии.
- Встроенный JavaScript проверен `node --check`; дубликатов HTML ID нет.
- Браузерные тесты текущей сборки выполнены в Chromium; инструкции локального запуска приведены выше.

- Таблицы аренды для всех 22 улиц берутся из индивидуальных тарифов карточек собственности; для каждой улицы проверяются базовая аренда, полный комплект, 1–4 дома и отель.

- В сетевом интерфейсе имя игрока и цвет не используются как доверенный HTML/CSS-ввод.
- Долг по заложенной собственности в финансовой статистике включает сумму выкупа с процентами: 55% цены объекта.

## Игровые фигурки участников

Для восьми игроков используются восемь отдельных SVG-фигурок: гоночный автомобиль, цилиндр, терьер, линкор, сапог, кошка, утка и велосипед. У миниатюр общий металлический материал с бликами и цветная эмалевая подставка, соответствующая цвету игрока. Один renderer используется для фишек на поле, карточек участников и панели имущества. Для обратной совместимости старые emoji-ID переводятся в те же индексы фигурок; при этом новые партии сохраняют стабильные текстовые ID токенов.
