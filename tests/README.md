# Автотест игровых механик

Тестовый набор работает отдельно от игрового интерфейса: он открывает корневой `index.html` в headless Chromium, подменяет сетевые отправки заглушками и запускает настоящие функции игровой логики в изолированных состояниях. Реальные комнаты и сохранённые партии не затрагиваются.

## Автоматический запуск

GitHub Actions запускает тесты при изменениях `index.html` или файлов `tests/` в `main`, а также при открытии PR в `main`.

Последний отчёт доступен во вкладке Actions, workflow **Monopoly mechanics autotest**.

## Запуск локально

Требуется Node.js 20+:

```bash
npm install --no-save playwright
npx playwright install chromium
node tests/run-mechanics.cjs
```

## Категории результатов

- **PASS** — сценарий прошёл.
- **GAP** — тест воспроизвёл известный пробел в текущих правилах; он явно попадает в отчёт, но не ломает обычный прогон.
- **FAIL** — регрессия, ошибка сценария или ошибка браузера; workflow завершается с ошибкой.

Чтобы временно сделать известные пробелы блокирующими для CI, запустите workflow вручную с параметром `strict=true`.

## Добавление теста

Добавляйте сценарии в `tests/mechanics-suite.browser.js`. Для обычной проверки используйте `test(name, fn)`. Для уже известного, но ещё не исправленного дефекта — `knownGap(name, detectGap)`; как только дефект исправлен, проверка автоматически перейдёт из GAP в PASS.


## Автотест пользовательского пути строительства

Отдельный workflow **Monopoly building user-path autotest** проверяет именно клики в интерфейсе Chromium, а не прямой вызов функции строительства.

Сценарии:
- открыть «Управление недвижимостью»;
- выбрать карточку улицы в списке имущества;
- проверить, что кнопка строительства показывает правильную улицу и активность;
- нажать кнопку и проверить списание денег, состояние карточки имущества, отрисовку дома на поле и остаток домов в банке;
- проверить тот же путь на мобильном экране 390 px;
- убедиться, что при недостатке денег, неполной цветовой группе или заложенной улице кнопка заблокирована;
- проверить, что при неравномерной застройке интерфейс предлагает улицу с наименьшим количеством домов.

Локальный запуск:

```bash
node tests/run-building-user-path.cjs
```

Помощник `tests/building-user-path.browser.js` загружается только тестовым раннером в отдельный браузерный прогон и не добавляется в опубликованный игровой интерфейс.
